# 🍔 Pixel Burguer — Arcade & Gourmet

O **Pixel Burguer** é um projeto de site para uma hamburgueria com temática gamer, desenvolvido utilizando **HTML, CSS e JavaScript**.

O projeto possui nove telas, incluindo página inicial, cardápio, carrinho de compras, login, cadastro, recuperação de senha, sobre, contato e painel administrativo.

O site apresenta uma identidade visual própria, com cores inspiradas no universo gamer, ilustrações de hambúrgueres e layout responsivo para computadores e celulares.

O cardápio conta com diferentes categorias de hambúrgueres, acompanhamentos e bebidas, além de uma **Área Kids**, com lanches infantis, combos especiais e sobremesas temáticas, como cupcakes decorados, cookies personalizados, milk-shakes coloridos e doces inspirados no universo dos jogos.

Entre as principais funcionalidades estão a busca de produtos, a organização do cardápio por categorias, a adição e remoção de itens do carrinho, o cálculo do valor total e a simulação de finalização de pedidos.

O projeto utiliza **HTML para estruturar as páginas, CSS para definir o visual e JavaScript para implementar as interações**. O armazenamento local é realizado por meio do `localStorage`.

O Pixel Burguer é um protótipo demonstrativo que busca representar o funcionamento de uma hamburgueria digital, unindo gastronomia, tecnologia e diversão para todas as idades. Atualmente, não possui banco de dados, autenticação real ou processamento de pagamentos.
